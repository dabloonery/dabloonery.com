# dabloonery.com

The dabloonery website. Plain HTML, CSS and a little JavaScript, served by GitHub Pages. No build step.

- `index.html`: every section; `site.js` shows one at a time from the address (`#tirekick`, `#rules`...).
- `tokens.css`, `components.css`: copied from the dabloonery kit. `site.css`: this site's layout.
- `fonts/`: Archivo and IBM Plex Mono (SIL Open Font License, `fonts/OFL.txt`), and a 5 KB cut of Bricolage Grotesque for the Tirekick wordmark (`fonts/BRICOLAGE-LICENSE.md`). All served from here.
- `img/`: Tirekick's icon and a screenshot from its store listing.

To preview, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
